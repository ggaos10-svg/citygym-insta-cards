# 카드뉴스 디자인 가이드 (Note 스타일)

2026-10-26 디자인 초기화. 기준은 시티짐 블로그 영상의 **"Note" 스타일**이다 (블로그 영상 `projects/citygym-blog-motion/note.tsx`와 같은 부품). 이전 디자인(남색 글자 카드, 곰돌이, AI 생성 그림, studio 스타일)은 쓰지 않는다. **캐릭터와 그림은 전부 코드로 그린다** (`remotion/src/art/Art.tsx`, 이미지 파일 없음).
문구 규칙(후킹, 장 흐름, 사실)은 `guide.md`와 `hooks.md`를 그대로 따른다. 이 파일은 **어떻게 보이고 움직이는지**만 정한다.

## 1. 한 장의 구성 (1080x1350, 6초 영상)

```
// 03 — 비교                     citygym · 금호점 · 3/7     ← 모노 글꼴 머리줄
계단 오를 때 무릎만 아프다면,                               ← 헤드라인 (한 단어씩 써짐)
엉덩이부터 빼세요.
+                                                    +
 ┌ Fig. 03 — 비교 ──────────────┐  ┌ 스티커 ┐
 │ ● ● ●  citygym-geumho.kr/#…   │                          ← 앱 창 카드
 │ [알약 버튼] [강조 알약]  [아이소메트릭 일러스트] │
 └───────────────────────────────┘           🍡 찹쌀떡   ← 오른쪽 아래, 포즈는 장 종류로 자동
+ → 다음 장 예고                                            ← 왼쪽 아래, 주황 모노 글꼴
```

- **헤드라인이 주인공이다.** 그 장의 말을 한 문장으로. 2줄 이내, 한 줄 16자 안팎. 78px 굵은 고딕.
- 헤드라인의 핵심 단어 하나는 `{red|단어}` 또는 `{hl|단어}`로 감싼다 → 주황색 + 밑줄.
- 앱 창 안의 **알약 버튼**(`lines`, `items`, `rows`)은 헤드라인을 짧게 쪼갠 메모다. 알약 하나 10자 이내. 두 번째 알약이 주황으로 강조된다 (가장 중요한 걸 두 번째에).
- 창 안 일러스트(`prop`)는 주제에 맞는 기구 하나.

## 2. 색과 글꼴

| 용도 | 값 |
|---|---|
| 바탕 (종이) | `#F4EFE6` |
| 글자 (먹) | `#1E1A16` |
| 강조 (주황) | `#F0532A` — 헤드라인 핵심 단어, 강조 알약, + 표시, 다음 장 예고 |
| 흐린 글자 | `#8C857B` — 머리줄, 창 주소줄 |
| 창 카드 | `#FFFDF8` + 3px 먹색 테두리 + 오른쪽 아래 딱딱한 그림자 |
| 터미널 | `#1C1B1F` 검정 카드, 모노 글꼴 |

- 헤드라인·알약: Noto Sans KR 900/700. 머리줄·창·터미널: 모노 글꼴. 반전 단어(punch): Black Han Sans.
- 그라데이션, 네온, 사진 배경 금지. 평평한 종이 위에 손그림 일러스트와 딱딱한 그림자.

## 3. 장 종류 (`type`) — 무엇이 화면에 놓이는지

| type | 화면 | 쓰는 곳 | 필드 |
|---|---|---|---|
| `hook` | 터미널 + 창 + 스티커 + 물음표 + 커서 클릭 | 1장 (표지) | `headline`, `lines`(2~3), `reveal`(스티커, 10자), `prop` |
| `highlight` | 창 + "시티짐 금호점" 스티커 + 커서 | 2장(반전·의외의 답), 설명 | `headline`, `lines`(2~3), `prop` |
| `section` | 창 + 큰 주황 번호 | 항목 시작 (01, 02…) | `headline`, `num`, `title`, `prop` |
| `compare` | 흑백 창(✕ 쪽) vs 컬러 창(○ 쪽) + VS 스티커 | 틀린 것 vs 맞는 것 | `headline`, `left`, `right`, `rows`([항목, 왼쪽, 오른쪽] 2~3개), `left_prop`, `prop` |
| `stat` | 창 + 큰 숫자 + 터미널 | 숫자 하나 강조 (facts.md 숫자만) | `headline`, `value`, `caption`, `kicker`, `prop` |
| `punch` | 큰 주황 단어 카드 | 반전 한 방 ("하지만,") | `headline`, `word`, `sub` |
| `checklist` | 체크 알약 + 클립보드 | 캡처용 요약 | `headline`, `title`, `items`(3~4) |
| `cta` | 건물 창 + 지하철 + 위치 스티커 | 마지막 장 | `headline`, `line`, `location` |

- 모든 장(마지막 제외)에 `next` (다음 장 예고, guide.md 규칙 그대로). 화면 왼쪽 아래 검정 스티커로 나온다. 12자 이내.
- **같은 `type`을 3장 연속 쓰지 않는다.** 항목이 3개면 비교 → 숫자(stat) → 설명(highlight)처럼 섞는다. 같은 화면이 반복되면 3장부터 이탈한다.
- **그림은 말과 맞아야 한다.** 헤드라인이 자세 얘기면 자세 그림(`squat_*`, `chair`), 기구 얘기면 그 기구. 맞는 그림이 없으면 그림이 필요 없는 `punch`나 `checklist`로 바꾸고, `note`에 "필요한 그림: ○○"를 적어 운영자가 추가하게 한다. 비슷한 그림으로 때우지 않는다.
- `compare`의 `rows`는 첫 칸을 비우면(`["", "무릎부터 내밀기", "엉덩이부터 빼기"]`) 값만 크게 나온다. 값은 8자 안팎.
- 알약(`lines`, `items`)은 10자 이내 — 폰에서 읽히는 크기를 유지하려면 짧아야 한다.
- 캐릭터는 **찹쌀떡**: 크림색 말랑한 몸, 주황 `CITYGYM` 머리띠, 점 눈, 분홍 볼, 가는 먹색 팔다리, 파란 그림자. 숨 쉬듯 말랑거리고 눈을 깜빡이며 머리띠 끈이 펄럭인다.
- 찹쌀떡 포즈는 장 종류로 자동: hook 걱정, section 손 흔들기, highlight 가리키기, stat 놀람, compare 엄지척, punch 환호, checklist 가리키기, cta 손 흔들기.
- `prop` 목록
  - 기구·장소: `machines` `stairs`(천국의계단) `booty`(부티빌더) `bench` `sauna`(반신욕기) `desk`(상담 데스크) `rack`(덤벨 랙) `board`(클립보드) `building`(센터 건물) `phone` `stopwatch` `subway`
  - 찹쌀떡 운동 시연 (옆모습, 2초마다 앉았다 일어남, 오른쪽 아래 찹쌀떡은 자동으로 숨김): `chair`(의자에 앉기) `squat_bad`(무릎 앞으로·뒤꿈치 들림) `squat_good`(엉덩이 뒤로) `squat_parallel`(허벅지 평행, 점선) `squat_heels`(뒤꿈치로 밀며 일어나기)
  - 도식: `feet_stance`(매트 위 발 위치: 어깨너비, 발끝 15°)
  - 전체 모습은 `cd remotion && npx remotion still src/index.tsx Gallery out.png`로 한 장에 볼 수 있다.

## 3-1. 새 그림 추가 (코드로)

목록에 없는 그림이 꼭 필요하면 `remotion/src/art/Art.tsx`에 컴포넌트를 하나 추가하고 맨 아래 `CODE_PROPS`에 이름을 등록한다. 검사기(`python -m cards check`)는 `CODE_PROPS`에 있는 이름만 통과시킨다. AI 이미지 생성은 쓰지 않는다.
- 기구·장소는 기존 아이소메트릭 도구로: `fit(W, D, H)`로 좌표계를 잡고, `Ground`(파란 그림자) → 뒤에서 앞 순서로 `B`(상자: `ORG`/`DARK`/`WOOD`/`CRM`/`METAL` 색 세트) → 면 위 무늬는 `onTop`/`onY`/`onX`. `Machines`, `Rack`, `Sauna`를 본보기로.
- 정면 물건(시계, 클립보드 등)은 `Stopwatch`, `Clipboard`처럼 평면 도형 + 파란 그림자.
- 운동 자세는 `MascotSide`에 자세(관절 각도: shin/thigh/torso)를 추가한다.
- 모두 `<Paper viewBox=…>`로 감싸면 손그림 떨림과 종이 질감이 자동으로 붙는다. 움직임은 `useCurrentFrame()`으로만 (CSS 애니메이션 금지), 8초 안에 반복되게.
- 굵은 먹색 테두리, 평평한 색 3단(윗면 밝게·왼쪽 중간·오른쪽 어둡게), 파란 그림자 `#3B5BDB`. 글자는 넣지 않거나 `CITYGYM` 정도.

## 4. 모션 (8초)

- 0.2초부터 헤드라인이 **한 단어씩 0.1초 간격으로** 올라오며 써진다 (2문장이면 약 1.5초에 완성).
- 창·터미널·스티커가 스프링으로 툭 튀어나오고(약간 기울어짐), 일러스트는 창 안에서 둥실 떠 있다.
- 터미널은 첫 줄을 타자 친다. 커서가 날아와 강조 알약을 클릭한다.
- 찹쌀떡은 아래에서 튀어 올라 계속 말랑하게 들썩인다.
- 1.3초에 다음 장 예고 스티커가 나타나 좌우로 까딱인다. 커서는 강조 알약의 오른쪽 끝을 눌러 글자를 가리지 않는다.
- 마지막 0.25초는 주황 종이가 화면을 쓸고 지나간다. 인스타가 영상을 반복할 때 "깜빡임"이 아니라 의도된 장면 전환으로 보이게 하려는 것.
- 미리보기 이미지(JPG)와 인스타 표지는 4초 지점 (모든 요소가 다 나오고, 스쿼트 시연이 가장 깊이 앉은 순간).
