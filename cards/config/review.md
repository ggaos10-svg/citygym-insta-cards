# 자체평가 지침 (매 게시물, 게시 전 자동)

초안을 쓰고 렌더가 끝나면, **이 글이 내 피드에 떴다고 생각하고** 넘겨서 읽을지 그냥 건너뛸지 검토한다. 아래 항목을 1~10점으로 매기고, 기준에 못 미치면 고쳐서 다시 렌더하고 다시 평가한다. 근거는 감이 아니라 화면이다.

## 1. 무엇을 보고 평가하나

- `media/<id>/review.jpg`: 모든 장을 **폰 화면 크기(가로 390px)**로 줄인 표. 위에서부터 0.4초(첫인상), 1.2초(글씨가 다 나온 직후), 4초(표지 화면) 세 줄.
- `media/<id>/01.jpg`: 1장 4초 화면 = 피드 썸네일·프로필 그리드 표지 (그리드는 가운데 3:4로 잘린다).
- 게시물 JSON의 문구와 캡션.
- 렌더된 그림을 보지 않고 매긴 점수는 무효다.

## 2. 평가 항목 (각 1~10점)

| # | 항목 | 이렇게 본다 |
|---|---|---|
| 1 | **첫 3초 이탈** | 0.4초·1.2초 화면에서 3초 안에 "나 얘기다/뭐지?"가 드는가. 첫 단어가 주제를 바로 알려주는가. 1장 표지(4초)가 썸네일 크기에서도 읽히고 궁금한가. 3초 안에 답이 보이거나 광고로 보이면 이탈 |
| 2 | **넘김** | 1→2, 2→3장을 넘길 이유가 있는가. 어느 장에서 빠져나갈지 예측하고 그 장을 고친다. "기구 홍보구나"가 보이는 순간 이탈 |
| 3 | **글자 크기** | review.jpg(390px)에서 헤드라인, 알약, 다음 장 예고가 눈 찡그리지 않고 읽히는가. 내용이 작은 글씨에만 있으면 감점 |
| 4 | **디자인** | 캐릭터·스티커·커서가 그림이나 글씨를 가리지 않는가. 빈 화면이 휑하지 않은가. 한 장에 눈길 가는 주인공이 하나인가 |
| 5 | **속도** | 헤드라인이 1.5초 안에 다 나오는가. 8초 동안 지루한 대기가 없는가. 넘기는 중에 다음 장이 비어 보이지 않는가 |
| 6 | **구조** | 표지 → 이유(2장만 봐도 말이 됨) → 한 장에 한 가지 → 캡처용 정리 → 행동 하나 (ig-carousel). 문단 같은 장 없음 |
| 7 | **흐름** | 1장의 약속을 본문이 지키는가. 2장이 답을 흘리지 않는가. 3장까지 첫 정보가 나오는가. 장과 장이 "그래서 → 그런데 → 그러니까"로 이어지는가 |
| 8 | **지루함** | 같은 그림·같은 구성이 반복되는가 (같은 그림 3장 연속, 같은 type 3장 연속은 검사기가 막는다). 4장째에 "또 같은 화면"이면 감점 |
| 9 | **저장** | 따라 할 팁이나 캡처할 정리가 있는가. 회원이 아니어도 얻어가는 게 있는가 |
| 10 | **공유** | "이거 ○○한테 보내야지" 할 대상이 바로 떠오르는가. 마지막 장이 그 대상을 콕 집는가 |
| 11 | **좋아요** | 공감("내 얘기네")이나 감탄("오 몰랐네") 포인트가 한 번 이상 있는가 |
| 12 | **댓글** | 3초 안에 답할 수 있는 질문인가 (숫자·한 글자·둘 중 하나). 정답이 갈리거나 자기 경험을 말하고 싶어지는가 |
| 13 | **바이럴·알고리즘** | 인스타가 많이 퍼뜨리는 신호를 만들 장치가 있는가. **보내기(DM 공유)**가 가장 강하고, 다음이 저장, 머무는 시간(장을 끝까지 넘기는가, 한 장에 오래 머물 이유), 댓글, 다시 보기 순. 2장이 혼자 떠도 말이 되는가 (안 넘긴 사람에게 2장부터 다시 보여줄 때가 있다). 캡션 첫 줄과 본문에 사람들이 검색할 말(금호역 헬스장, 운동 이름)이 자연스럽게 들어가는가. "남들이 몰랐던 사실, 반전, 논쟁거리, 내 얘기 같은 공감" 중 하나가 분명한가. 점수는 가능성 판단이지 보장이 아니다 |
| 14 | **사실·말투** | 센터 정보는 facts.md에 있는 것만. AI 티 없음 (ig-human): em dash(—), "완벽 가이드", "~의 모든 것", 번역투, 같은 형식 3단 나열 남발, 과장("한 번도 안 썼는데요" 같은 말이 사실처럼 읽히면 감점) |

## 3. 통과 기준

- 14개 평균 **8.0 이상**이고 **7점 미만 항목이 없으며**, 사실 위반이 0이면 통과.
- 못 미치면 점수가 가장 낮은 항목부터 고친다. 고칠 수 있는 것: 게시물 JSON(문구, 장 종류, 순서, 그림 선택, 캡션)과 design.md 3-1에 따른 새 그림 1개. 렌더러·검사기·설정은 고치지 않는다 (디자인 자체의 문제면 `note`에 적어 운영자에게 넘긴다).
- 평가 → 수정 → 렌더 → 재평가는 **최대 3번**. 3번째에도 통과 못 하면 `status: pending`, `note`에 남은 문제를 적는다.

## 4. 기록

게시물 JSON에 마지막 평가를 남긴다 (렌더에는 영향 없음):

```json
"review": {
  "round": 2,
  "scores": { "first3s": 8, "swipe": 8, "text": 9, "design": 8, "pace": 9, "structure": 8, "flow": 8, "boredom": 8, "save": 9, "share": 8, "like": 8, "comment": 9, "viral": 8, "facts": 10 },
  "overall": 8.5,
  "verdict": "1장에서 멈추고 끝까지 넘김. 4장이 가장 약함",
  "fixed": ["3장 결론이 미리 보여 2·3장 순서 교체", "6장 체크리스트를 행동 팁으로"]
}
```

## 5. 보고 형식 (루틴 마지막 메시지)

1. 피드에 떴을 때: 멈출까 / 어디까지 넘길까 / 어디서 이탈할까
2. 항목별 점수 표 (위 14개) + 평균
3. 고친 것 (라운드별)
4. 남은 약점, 최종 상태 (approved / pending + 이유)
